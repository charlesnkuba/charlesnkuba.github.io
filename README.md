# Charles Nkuba — professional portfolio

A responsive, buildless portfolio for Charles Nkuba covering software development, systems engineering studies, networking and internship experience.

## Files

- `index.html`: complete portfolio, including styles. No package installation or build step.
- `.nojekyll`: serves the website as static files on GitHub Pages.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a repository named `charlesnkuba.github.io` under the `charlesnkuba` account.
2. Upload these files to its default branch.
3. In Settings → Pages, select Deploy from a branch, choose the default branch and `/ (root)`, then save.
4. Wait for GitHub's Pages deployment to finish. The intended address is `https://charlesnkuba.github.io/`; this address is not verified as live in this draft.
