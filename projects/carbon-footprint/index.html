Design and Implementation of a Web-Based Carbon Footprint Tracking System.

A final-year project by Charles Nkuba at Information and Communications University, focusing on transport, electricity and fuel activities.

CO₂ACTIVITY → ESTIMATE → INSIGHT
What is live here: the project overview and planned system design. This page does not run the Flask application or calculate emissions. Application source and a working backend demonstration will be added when available.

Project scope

What the system is being developed to do

Capture everyday activities

A user-friendly interface for transportation, electricity consumption and fuel usage data.

Estimate emissions consistently

Predefined emission factors with their units and sources, matched to each activity category.

Keep historical records

A database structure for storing activity entries and associated carbon emission estimates.

Show trends and reduction tips

Charts and dashboards to explore recorded emissions, with rule-based recommendations. AI integration is excluded.

Planned architecture

A three-tier web application

PresentationHTML · CSS · JavaScript
ApplicationPython · Flask · Emission calculations
DataSQLite · Activities · Emission records

The static project page is hosted on GitHub Pages. The Flask backend needs a server environment that can run Python.

Development plan

Implementation phases

  1. Project skeleton and landing page
  2. Registration, login and SQLite storage
  3. Activity form, emission factors and calculation logic
  4. Dashboard, charts and reports
  5. Recommendations, profiles and exports
  6. Deployment, testing and documentation

These are the planned phases, not a claim that every feature is implemented.
